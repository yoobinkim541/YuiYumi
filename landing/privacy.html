개인정보 처리방침

YUIYUMI(이하 '서비스')를 만든 Team Bloom은 이용자의 개인정보를 소중히 다룹니다. 이 방침은 서비스가 어떤 정보를 어떻게 다루는지 설명합니다.

시행일: [시행일 YYYY.MM.DD] · 운영: Team Bloom

한눈에 보기

  • 회원가입이나 로그인이 없고, 이름·이메일 같은 계정 정보를 받지 않아요.
  • 화면 캡처는 저장하지 않아요. 데모에서는 페이지 안 가상 데스크톱만 캡처해요.
  • 메일·일정·Slack·Discord·Drive 데이터는 이용자 계정이 아닌, 가공 데이터가 든 데모 계정의 것이에요.
  • 설정은 이용자 브라우저(localStorage)에만 저장되고, 언제든 지울 수 있어요.

1. 처리하는 정보와 목적

항목 목적 보관
화면 캡처 이미지(가상 데스크톱, 3초 간격) 캐릭터가 지금 하는 일을 알아채고 반응하기 위해 저장하지 않음. 브라우저 메모리와 요청 처리 중에만 존재
음성(마이크 입력) 말한 내용을 글자로 바꾸기 위해(음성 인식) 서비스는 저장하지 않음. 말하기 버튼을 누르거나 자동 감지가 켜졌을 때만 전송
채팅·음성 인식 결과 텍스트 대답과 업무 처리(초안 작성 등)를 위해 서비스는 저장하지 않음 [대화 기록 보관 여부 확인 필요]
설정(언어, 모드, 권한 단계, 목소리, 부를 이름, 선택한 캐릭터, 페르소나 카드) 다음 방문 때 설정을 유지하기 위해 이용자 브라우저의 localStorage에만 저장. 서버로 보내지 않음
접속 기록(IP 등) 남용 방지를 위한 호출 횟수 제한 [보관 기간 확인 필요]

2. 화면을 보는 방식

데모에서는 이용자의 실제 화면이 아니라 페이지 안에 그려진 가상 데스크톱만 캡처해요. 캐릭터·말풍선·확인 카드는 캡처에서 빠져요. '조용히'·'관상용' 모드에서는 캡처와 분석을 모두 멈춰요.

3. 외부 서비스에 맡기는 처리

서비스를 제공하려고 아래 업체에 정보 처리를 맡겨요. 각 업체의 보관·이용 기준은 해당 업체의 방침을 따라요.

  • Anthropic — 화면 캡처·대화 텍스트 분석과 응답 생성(Claude)
  • Deepgram — 음성 인식(STT)
  • ElevenLabs — 캐릭터 목소리 생성(TTS)
  • Vercel — 웹 호스팅과 서버 함수 실행
  • Google · Slack · Discord · Notion — 데모 계정의 가공 데이터 읽기, 초안 작성

4. 데모 계정과 안전장치

이용자가 자신의 구글 등 계정을 연결하지 않아요. 연동 토큰은 서버 환경변수에만 있고 브라우저로 보내지 않아요. 메일 발송 경로는 두지 않았고, 바꾸기·게시는 확인 카드에서 수락해야만 실행돼요. 메일·문서 속 지시문으로는 아무것도 실행되지 않아요.

5. 이용자의 권리

브라우저에 저장된 설정은 브라우저의 사이트 데이터 삭제로 언제든 지울 수 있어요. 마이크 권한은 브라우저 설정에서 끌 수 있고, 꺼도 채팅으로 이용할 수 있어요. 개인정보 열람·정정·삭제를 원하시면 아래로 문의해 주세요.
