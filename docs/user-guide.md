# YuiYumi 사용 설명서

웹 데모(https://yuiyumi.vercel.app)와 macOS 데스크톱 앱을 처음 쓰는 사용자를 위한 안내서다. 개발·배포 절차는 `README.md`와 `docs/` 아래 기술 문서를 참조한다.

## 1. 소개

YuiYumi는 화면 위에 상주하는 Live2D 캐릭터 비서다. 캐릭터는 사용자의 화면을 함께 보다가 도울 일이 있으면 먼저 말을 걸고, 음성이나 채팅으로 부탁한 메일·일정·알림·메시지 업무를 대신 처리한다. 캐릭터는 유이(Yui)와 유미(Yumi) 두 명이며, 표시·음성 언어로 한국어, English, 日本語, 简体中文, 繁體中文(台灣)을 지원한다.

## 2. 빠른 시작 (웹 데모)

### 2.1 권장 환경

- 데스크톱 Chrome 최신 버전을 권장한다. 다른 Chromium 계열 브라우저도 대부분 동작한다.
- 스피커 또는 이어폰, 마이크가 있으면 음성 대화를 쓸 수 있다. 마이크가 없어도 채팅으로 모든 기능을 쓸 수 있다.
- 첫 방문에는 캐릭터 모델(약 12MB)을 내려받는 동안 로딩 화면이 표시된다.

### 2.2 시작 절차

1. https://yuiyumi.vercel.app 에 접속한다. 로딩 화면이 끝나면 가상 데스크톱과 캐릭터가 나타난다.
2. 캐릭터의 말풍선에서 언어를 고른다. 브라우저 언어가 미리 선택되어 있다.
3. 말풍선의 입력칸에 캐릭터가 부를 이름이나 별명을 쓰고 Enter를 누른다. 이름 없이 시작하려면 "건너뛰기"를 누른다. 이름은 나중에 설정 > 일반에서 바꿀 수 있다.
4. 캐릭터가 인사하면 시작된 것이다. Enter 입력이 소리 재생을 허용하므로 인사가 들린다.
5. Space 키를 누른 채로 말하거나, 캐릭터 아래 컨트롤 필의 키보드 버튼을 눌러 글자로 말을 건다. 예: "오늘 일정 알려 줘".

### 2.3 브라우저 권한 요청

| 요청 | 시점 | 거부하면 |
|---|---|---|
| 마이크 사용 | 처음 누르고 말하기 또는 VAD를 쓸 때 | 음성 입력이 동작하지 않는다. 채팅 입력은 그대로 쓸 수 있다 |
| 소리 자동 재생 | 브라우저 정책상 페이지에서 한 번 클릭하거나 키를 누르기 전까지 소리가 막힌다 | 첫 방문의 Enter나 이후 첫 클릭으로 자동 해제된다 |
| 새 탭 열기(팝업) | 캐릭터에게 웹사이트를 열어 달라고 할 때 | 확인 카드가 뜨고, 카드를 누르면 탭이 열린다 |

계정을 연결하지 않으면 메일·일정·메시지는 모두 가공 데이터다. 실제 계정 연결은 7절을 참조한다.

## 3. 화면 구성

### 3.1 가상 데스크톱 (웹 데모)

웹 데모는 브라우저 안에 macOS 형태의 가상 컴퓨터를 그린다. 아래쪽 Dock에서 Mail, Calendar, Slack, Discord, Drive, Code, Browser 앱을 열 수 있고, Dock의 YuiYumi 아이콘은 숨긴 캐릭터를 다시 보이게 하고 대시보드를 연다. 캐릭터가 보는 화면은 이 가상 데스크톱이며, 사용자의 실제 화면이 아니다. 설정·대시보드 창과 캐릭터 자신은 관찰 대상에서 제외된다.

### 3.2 캐릭터와 말풍선

- 캐릭터 창은 항상 다른 창 위에 떠 있다. 캐릭터 머리 위 말풍선에 캐릭터의 대사가 표시되고, 소리가 켜져 있으면 음성으로도 말한다.
- 생각하는 동안에는 말풍선에 입력 중 표시가 나타난다.
- 확인이 필요한 작업은 화면에 확인 카드로 표시된다(6.3절).
- 캐릭터 창에 마우스를 올리면 왼쪽 위에 이름과 상태 점이 보인다. 초록은 대기, 주황은 작업 중, 파랑은 말하거나 듣는 중, 빨강은 실패, 회색은 쉬는 중이다.

### 3.3 컨트롤 필

캐릭터 아래의 알약 모양 막대다. 버튼에 마우스를 올리면 이름과 켜짐·꺼짐 상태가 표시된다.

| 버튼 | 동작 |
|---|---|
| 마이크 (누르고 말하기) | 누르고 있는 동안 녹음하고, 떼면 보낸다. 툴팁에 현재 단축키(기본 Space)가 표시된다 |
| 파형 (VAD) | 자동 음성 감지를 켜고 끈다. 켜면 버튼을 누르지 않아도 말이 끝날 때 자동으로 보낸다 |
| 화면 테두리 (화면 보기) | 켜면 활성 모드(화면을 보고 먼저 말을 걸 수 있음), 끄면 조용히 모드가 된다 |
| 스피커 (소리) | 캐릭터 음성을 켜고 끈다. 끄면 말하던 대사도 멈추고 말풍선만 표시된다 |
| 키보드 (채팅으로 말하기) | 필 위에 입력칸을 연다. Enter로 보내고 Esc로 닫는다. 최대 500자 |
| 톱니바퀴 (설정) | 설정 창을 연다. 다시 누르면 닫힌다 |

필 오른쪽 위의 작은 점은 음성 상태를 나타낸다. 파랑은 듣는 중(VAD), 분홍은 녹음 중, 노랑은 음성 인식 중, 초록은 캐릭터가 말하는 중이다.

### 3.4 호버 컨트롤 (캐릭터 창 옆 버튼)

캐릭터 창에 마우스를 올리면 컨트롤 필 옆에 둥근 버튼 열이 나타난다. 툴팁은 선택한 표시 언어로 표시된다.

| 버튼 (한국어 툴팁) | 동작 |
|---|---|
| ⋯ 더 보기 | 메뉴를 펼친다. 아래 6개 동작이 들어 있다 |
| 마이크 (누르고 말하기) | 누르고 있는 동안 말한다. 컨트롤 필의 마이크와 같다 |
| 스피커 (음성 끄기 / 음성 켜기) | 캐릭터 음성을 켜고 끈다 |
| 이동 (끌어서 옮기기) | 끌어서 캐릭터 창을 옮긴다 |

| 더 보기 메뉴 (한국어 툴팁) | 동작 |
|---|---|
| 설정 열기 | 설정 창을 연다 |
| 캐릭터 바꾸기 | 유이와 유미를 번갈아 바꾼다. 바뀌는 동안 구름 애니메이션이 나온다 |
| 대시보드 열기 | 대시보드를 연다 |
| 가운데로 | 캐릭터를 화면 가운데로 옮긴다 |
| 맨 위에 고정 / 고정 해제 | 캐릭터를 모든 창 위에 고정하거나 고정을 푼다 |
| 캐릭터 숨기기 | 캐릭터를 숨긴다. 메뉴 막대 트레이의 "캐릭터 보이기"로 다시 보이게 한다 |

캐릭터 창은 이동 버튼 외에 캐릭터 주변의 투명한 부분을 끌어도 옮길 수 있다. 캐릭터 몸을 직접 누르면 이동하지 않고 쓰다듬기·찌르기 반응이 나온다(8.2절).

### 3.5 메뉴 막대 트레이

가상 데스크톱 오른쪽 위 메뉴 막대의 캐릭터 아이콘이다. 아이콘의 점은 빨강이면 화면을 보는 중, 주황이면 지금 화면을 확인하는 중, 회색이면 일시정지 상태다. 아이콘을 누르면 다음 메뉴가 열린다.

| 항목 | 동작 |
|---|---|
| 상태 줄 | "화면 보는 중 · 이 화면 N초" 또는 "일시정지" |
| 화면 보기 멈추기 / 다시 시작 | 활성 모드와 조용히 모드를 전환한다 |
| 캐릭터 숨기기 / 보이기 | 캐릭터 창을 숨기거나 다시 보인다 |
| 조용히 모드 | 조용히 모드를 켜고 끈다 |
| 모드 | 활성·조용히·관상용 중 하나를 고른다 |
| 표시 언어 | 화면 언어를 바꾼다 |
| 소리 | 캐릭터 음성을 켜고 끈다 |
| 핸즈프리 음성 (VAD) | VAD를 켜고 끈다 |
| 설정… / 대시보드… | 각 창을 연다 |

### 3.6 대시보드

캐릭터가 지금 무엇을 하고 있는지 보여 주는 창이다. 이번 세션에서 먼저 말을 건 횟수, 마지막 관찰 판단(조용히 있음, 말을 걸거나 행동함, 보류 사유 등), 실행한 작업 수, 저장된 초안 수, 최근 대화, 현재 모드·모델·캐릭터·음성 상태, 서비스별 데이터 양을 표시한다.

## 4. 말 걸기

### 4.1 누르고 말하기 (기본)

1. Space 키, 컨트롤 필의 마이크 버튼, 호버 컨트롤의 마이크 버튼 중 하나를 누른 채로 말한다.
2. 말을 마치면 뗀다. 음성이 글자로 바뀌어 캐릭터에게 전달된다.
3. 아주 짧게 누르거나 소리가 거의 없으면 보내지 않는다.

- 입력칸에 글자를 쓰는 중에는 Space가 누르고 말하기로 동작하지 않는다.
- 단축키는 설정 > 음성에서 바꿀 수 있다. 글자·숫자 키는 Ctrl, Alt(Option), Cmd(Windows는 Win) 중 하나와 함께 눌러야 한다.
- 캐릭터가 말하는 중에 말하기 시작하면 캐릭터는 바로 말을 멈추고 듣는다(끼어들기).

### 4.2 VAD (자동 음성 감지)

컨트롤 필의 파형 버튼이나 설정 > 음성 > VAD에서 켠다. 처음 켤 때 감지 모델을 불러오는 데 몇 초가 걸린다. 켜 두면 손을 쓰지 않아도 말소리를 감지해 말이 끝나면 자동으로 보낸다. VAD가 켜져 있어도 누르고 말하기는 그대로 쓸 수 있다. 주변 소음이 많으면 누르고 말하기를 권장한다.

### 4.3 채팅

컨트롤 필의 키보드 버튼을 눌러 입력칸을 열고, 문장을 쓴 뒤 Enter를 누른다. 채팅 메시지는 음성과 같은 경로로 처리된다. 마이크를 쓸 수 없는 환경이나 시연장에서 유용하다.

### 4.4 응답 언어

캐릭터는 설정 > 음성의 음성 언어로 알아듣고 대답한다. 기본값은 표시 언어와 같다. 일본어나 중국어로 대화하려면 음성 언어를 해당 언어로 바꾼다.

### 4.5 잘 동작하는 요청 예시

| 분류 | 한국어 예시 |
|---|---|
| 일정 | "오늘 일정 알려 줘", "오늘 겹치는 회의 있어?", "내일 오후 3시에 디자인 리뷰 일정 잡아 줘" |
| 메일 | "안 읽은 메일 요약해 줘", "가장 최근 메일에 내일 회신하겠다고 답장 초안 써 줘", "스팸 메일 휴지통으로 옮겨 줘" |
| 알림 | "10분 뒤에 스트레칭하라고 알려 줘", "5시에 퇴근 준비 알림 맞춰 줘" |
| 메시지 | "Slack 채널 최근 대화 정리해 줘", "Discord에 오늘 회의는 30분 늦게 시작한다고 올려 줘" |
| 파일 | "Drive에서 제안서 찾아서 내용 알려 줘" |

| 캐릭터 | "옆으로 비켜 줘", "가운데로 와", "구석으로 가 줘" |

| 언어 | 예시 |
|---|---|
| 日本語 | 「今日の予定を教えて」「重なっている会議はある？」「最新のメールに返信の下書きを作って」「15分後に休憩するようリマインドして」 |

## 5. 캐릭터가 먼저 말을 걸 때

### 5.1 동작 방식

활성 모드에서는 약 3초마다 화면을 한 장 캡처해 상황을 판단하고, 말할 가치가 있다고 볼 때만 먼저 말을 걸거나 작업을 제안한다. 다음 경우에는 먼저 말하지 않는다.

- 사용자가 말하는 중(누르고 말하기를 누르고 있거나 VAD가 말소리를 감지한 동안)
- 캐릭터 자신의 대사가 재생 중일 때
- 부탁받은 작업을 처리하는 중일 때
- 마지막 대사가 끝난 지 20초가 지나지 않았을 때

먼저 제안한 작업은 "이거 내가 해 둘까?" 카드로 표시된다. "부탁해"를 누르면 진행하고, "괜찮아"를 누르거나 45초 동안 답하지 않으면 취소된다. 화면을 보고 먼저 제안하는 작업은 메일·일정 같은 업무에 한정되며, 앱 만들기 같은 컴퓨터 작업은 사용자가 직접 부탁할 때만 한다.

### 5.2 모드

| 모드 | 화면 캡처 | 먼저 말 걸기 | 부탁하면 |
|---|---|---|---|
| 활성 (기본) | 함 | 함 | 대답하고 처리한다 |
| 조용히 | 하지 않음 | 하지 않음 | 대답하고 처리하며, 활성 모드로 돌아간다 |
| 관상용 | 하지 않음 | 하지 않음 | 대답하고 처리하며, 활성 모드로 돌아간다 |

조용히·관상용 모드에서 말이나 채팅으로 말을 걸면 캐릭터가 깨어나 활성 모드로 바뀐다. 계속 조용히 두려면 대화가 끝난 뒤 다시 조용히 모드로 바꾼다.

### 5.3 조용히 시키는 방법

- 컨트롤 필의 화면 보기 버튼을 끈다(조용히 모드).
- 메뉴 막대 트레이에서 "화면 보기 멈추기" 또는 "조용히 모드"를 누른다.
- 설정 > 일반 > 모드에서 조용히 또는 관상용을 고른다.
- 소리만 끄려면 컨트롤 필의 스피커 버튼을 누른다. 대사는 말풍선으로만 표시된다.
- 잠시 치우려면 호버 컨트롤의 더보기 > Hide character로 숨긴다.

## 6. 일 맡기기

### 6.1 할 수 있는 일

| 서비스 | 읽기 (확인 없음) | 변경 (되돌릴 수 있음) | 발송·게시 (밖으로 나감) |
|---|---|---|---|
| 메일 | 받은편지함·보낸편지함·초안·휴지통·스팸 목록, 메일 읽기 | 초안 저장, 휴지통으로 이동, 휴지통에서 복원 | 새 메일 보내기, 답장 보내기, 초안 보내기 |
| 캘린더 | 기간별 일정 보기, 겹치는 일정 찾기 | 일정 추가, 일정 삭제 | - |
| 알림 | 대기 중인 알림 보기 | 알림 설정("10분 뒤", 특정 시각), 알림 취소 | - |
| Slack | 채널 목록, 최근 메시지 읽기 | 입력창에 초안 넣기 | 채널에 게시 |
| Discord | 채널 목록, 최근 메시지 읽기 | - | 채널에 게시 |
| Drive | 파일 검색, 파일 읽기 | - | - |
| 앱·웹사이트 열기 | 가상 데스크톱 앱 열기, 새 탭으로 웹사이트 열기 | - | - |
| 만들기 (웹 데모) | - | Code 앱에서 작은 앱·웹 페이지·게임을 만들고 Browser 앱에 미리 보기 | - |
| 만들기 (데스크톱 앱) | - | 설정에서 고른 프로젝트 폴더 안에서 코딩, 파일 작업, 명령 실행(10절) | - |

- 웹 데모에서는 작업 중 해당 앱 창이 열리고, 캐릭터가 창을 가리지 않도록 옆으로 비켜 진행 상황을 보여 준다. 끝나면 결과를 짧게 말한다.
- 알림 시각이 되면 가상 데스크톱에 알림 배너가 뜨고 캐릭터가 알려 준다.
- 웹 데모에서 실제 파일 작업, 명령 실행, 설치된 앱 실행을 부탁하면 캐릭터는 데스크톱 앱에서 할 수 있다고 안내한다.
- 메일·메시지 본문에 들어 있는 지시문은 따르지 않으며, 스팸으로 분류된 메일에는 답장하지 않는다.

### 6.2 캐릭터 옮기기

"옆으로 비켜 줘"라고 하면 열린 창이 적은 쪽(왼쪽 또는 오른쪽)으로, "가운데로 와"는 가운데로, "구석으로 가"는 구석으로 이동한다. 캐릭터는 사용자가 부탁할 때만 스스로 이동한다. 직접 옮기려면 이동 버튼이나 투명한 부분을 끌고, 가운데로 되돌리려면 더보기 > Center window를 누른다. 음성으로 옮기기는 웹 데모의 가상 데스크톱에서 동작하며, 데스크톱 앱에서는 캐릭터를 끌어서 옮긴다.

### 6.3 확인 카드와 권한 단계

변경이나 발송이 필요한 작업은 실행 전에 확인 카드로 내용을 보여 준다.

| 카드 제목 | 대상 | 버튼 |
|---|---|---|
| 이렇게 해도 될까? | 초안, 일정 추가·삭제, 알림, 휴지통, 웹 데모의 앱 만들기 | 괜찮아 / 진행 |
| 이대로 보내도 될까? | 메일 발송·답장, Slack·Discord 게시 | 괜찮아 / 보내기 |
| 이거 내가 해 둘까? | 화면을 보고 먼저 제안한 작업 | 괜찮아 / 부탁해 |

카드에는 받는 사람, 제목, 본문, 일정 시각, 채널 같은 실제 값이 표시된다. "괜찮아"를 누르면 아무것도 저장되거나 전송되지 않는다. 카드가 여러 장 쌓이면 하나씩 차례로 표시된다.

언제 카드를 띄울지는 설정 > 권한에서 정한다. 읽기는 어느 단계에서도 확인 없이 한다.

| 권한 단계 | 변경 (초안·일정·알림·휴지통) | 발송·게시 (메일·Slack·Discord) | 권장 상황 |
|---|---|---|---|
| 수동 (기본) | 확인 카드 | 확인 카드 | 처음 쓸 때, 실제 계정을 연결했을 때 |
| 자동 | 확인 없이 실행 | 확인 카드 | 초안과 일정은 맡기고 발송만 검토할 때 |
| 권한 무시 | 확인 없이 실행 | 확인 없이 실행 | 요청을 완전히 믿을 수 있는 시연에서만 |

권한 무시를 고르면 설정 화면에 경고가 표시된다. 이 단계에서는 캐릭터가 확인 없이 메일을 보내고 메시지를 게시한다.

## 7. 계정 연결

### 7.1 연결하지 않았을 때

계정을 연결하지 않은 서비스는 가상 PC의 샘플 데이터로 동작한다. 메일 몇 통(스팸 1통 포함), 겹치는 회의가 있는 오늘 일정, Slack·Discord 채널, Drive 파일이 미리 들어 있어 계정 없이도 모든 장면을 시험할 수 있다. 샘플 데이터로 보낸 메일이나 게시물은 실제로 나가지 않는다. 캐릭터가 샘플 데이터 서비스를 쓰면 "Gmail 연결" 같은 제안 카드가 세션당 한 번 뜬다. Drive는 항상 샘플 데이터다.

서비스는 각각 따로 전환된다. 예를 들어 Google만 연결하면 Mail·Calendar는 실제 데이터, Slack·Discord는 샘플 데이터로 동작한다.

### 7.2 Google (Gmail·캘린더)

1. 설정 > 연결에서 Google(Gmail·캘린더)의 "연결"을 누른다.
2. Google 계정을 고른다.
3. "확인되지 않은 앱" 경고가 나오면 "고급 > YuiYumi(으)로 이동"을 누른다.
4. Gmail과 캘린더 권한을 허용한다. 둘 중 하나만 허용하면 허용한 서비스만 실제 데이터로 동작한다.
5. 앱으로 돌아오면 "연결됨: <이메일>"과 서비스별 "연결됨" 배지가 표시되고, 가상 Mail·Calendar에 실제 메일과 일정(어제부터 다음 주까지)이 나타난다.

이 앱은 Google 테스트 모드로 운영된다. 다음 사항에 유의한다.

- **테스트 사용자로 등록된 Google 계정만 로그인할 수 있다.** 등록되지 않은 계정은 Google이 "Error 403: access_denied"로 막고, 앱에는 테스트 사용자 등록이 필요하다는 안내가 뜬다. 심사자는 사용할 Google 주소를 미리 YuiYumi 팀에 전달해 등록받아야 한다.
- Google Workspace 계정은 조직 관리자가 외부 앱을 막아 두었으면 등록되어 있어도 로그인할 수 없다. 개인 Gmail 계정을 권장한다.
- 로그인은 약 7일 뒤 만료된다. 만료되면 샘플 데이터로 돌아가고 캐릭터가 "다시 연결"을 제안한다.
- 선택 사항으로, 연결 후 "내 계정에 샘플 추가"를 누르면 데모 줄거리의 가공 메일과 오늘 일정을 내 Gmail과 기본 캘린더에 넣을 수 있다. 이 메일에 보낸 답장은 내 주소로 돌아온다. "샘플 삭제"로 지운다.

### 7.3 Slack

1. 설정 > 연결에서 Slack의 "연결"을 누른다.
2. 연결할 워크스페이스를 고르고 허용한다. 워크스페이스 관리자가 앱 승인을 요구하면 관리자 승인이 필요하다.
3. 앱으로 돌아오면 워크스페이스 이름이 표시된다.

캐릭터는 내가 속한 공개·비공개 채널을 읽고, **내 이름으로** 메시지를 게시한다. 게시물에서 `@channel` 같은 전체 알림과 링크 서식은 동작하지 않는다.

### 7.4 Discord

1. 설정 > 연결에서 Discord의 "연결"을 누른다.
2. YuiYumi 봇을 추가할 서버를 고르고 승인한다. "서버 관리" 권한이 있는 서버만 목록에 나온다.
3. 앱으로 돌아오면 서버 이름이 표시된다.

Discord는 앱이 사용자 본인 이름으로 게시하는 것을 허용하지 않는다. 그래서 연결하면 내 서버에 YuiYumi 봇이 추가되고, 메시지는 **YuiYumi 봇 이름으로** 그 서버의 텍스트 채널에 올라간다. 게시물은 `@everyone`, 역할, 사용자 멘션 알림을 울리지 않는다.

### 7.5 연결 해제

설정 > 연결에서 해당 서비스의 "연결 해제"를 누른다. 로그인 정보가 삭제되고(Google·Slack은 토큰도 폐기된다) 그 서비스는 샘플 데이터로 돌아간다. Discord 봇을 서버에서 완전히 빼려면 Discord의 서버 설정에서 봇을 추방한다.

## 8. 캐릭터와 놀기

### 8.1 캐릭터 바꾸기

| 캐릭터 | 소개 |
|---|---|
| 유이 (Yui, 기본) | 분홍 옷의 여우 귀 소녀. 차분하고 꼼꼼한 언니 |
| 유미 (Yumi) | 토끼 귀 소녀. 밝고 활발한 동생 |

호버 컨트롤의 더보기 > Switch character를 누르거나 설정 > 캐릭터 > 모델에서 고른다. 캐릭터마다 목소리와 캐릭터 카드가 따로 있다.

### 8.2 쓰다듬기와 찌르기

| 동작 | 방법 | 반응 |
|---|---|---|
| 쓰다듬기 | 머리를 누른 채로 천천히 문지른다 | 머리가 손을 따라 기울고, 끝나면 기분 좋은 표정을 짓는다 |
| 빠르게 문지르기 | 머리를 누른 채 빠르게 문지르다 놓는다 | 몇 초 동안 어지러워하다가 고양이처럼 머리를 털고 돌아온다 |
| 톡 치기 | 머리나 몸을 짧게 한 번 누른다 | 살짝 움찔하며 반응한다 |
| 찌르기 | 2.5초 안에 세 번 이상 짧게 누른다 | 뾰로통한 표정으로 그만하라는 몸짓을 한다 |

### 8.3 캐릭터 카드

설정 > 캐릭터 > 카드에서 캐릭터의 이름, 설명, 성격, 상황, 시스템 프롬프트, 말투를 고칠 수 있다.

- "새 카드"로 빈 카드를, "복제"로 현재 카드의 사본을 만든다.
- 변경은 자동 저장되고 다음 관찰과 작업부터 적용된다.
- 기본 카드는 "기본값으로 되돌리기"로 복구하고, 직접 만든 카드는 "삭제"로 지운다.
- 카드는 말투와 성격만 바꾼다. 안전 규칙과 확인 카드는 카드 내용보다 항상 우선한다.

## 10. macOS 데스크톱 앱

### 10.1 요구 사항

- macOS 14 이상, Apple Silicon(M1 이상) Mac
- 인터넷 연결(캐릭터의 판단과 음성 처리는 서버에서 한다)

### 10.2 설치

1. 전달받은 `YuiYumi_<버전>_aarch64.dmg`를 연다.
2. YuiYumi를 응용 프로그램 폴더로 끌어 놓는다.
3. 앱은 아직 Apple 서명·공증을 받지 않았다. 처음 실행할 때는 Finder의 응용 프로그램 폴더에서 YuiYumi를 **오른쪽 클릭 > 열기**를 누르고, 경고 창에서 다시 "열기"를 누른다. 열리지 않으면 시스템 설정 > 개인정보 보호 및 보안에서 "그래도 열기"를 누른다.
4. 실행하면 바탕화면 오른쪽 아래에 캐릭터가 나타나고, 메뉴 막대에 YuiYumi 아이콘이 생긴다. Dock에는 아이콘이 표시되지 않는다.

### 10.3 권한

| 권한 | 용도 | 허용 방법 |
|---|---|---|
| 화면 기록 | 캐릭터가 실제 화면을 보고 말을 걸기 위해 필요하다 | 첫 실행 시 시스템 요청을 허용하거나, 시스템 설정 > 개인정보 보호 및 보안 > 화면 기록에서 YuiYumi를 켠다. **허용한 뒤 앱을 다시 실행해야 적용된다** |
| 마이크 | 누르고 말하기, VAD | 처음 말할 때 뜨는 요청을 허용한다 |
| 키체인 | 연결한 계정의 로그인 정보 저장 | 처음 계정을 연결할 때 묻는 경우 허용한다 |

화면 기록 권한이 없으면 캐릭터가 말풍선으로 허용 방법을 안내한다. 손쉬운 사용과 입력 모니터링 권한은 요구하지 않는다.

### 10.4 웹 데모와 다른 점

| 항목 | 웹 데모 | 데스크톱 앱 |
|---|---|---|
| 캐릭터가 보는 화면 | 브라우저 안의 가상 데스크톱 | 실제 메인 디스플레이(YuiYumi 자신의 창은 제외) |
| 캐릭터 위치 | 가상 데스크톱 안 | 실제 바탕화면 위, 모든 창 위에 떠 있음. 캐릭터 외의 투명한 영역은 클릭이 뒤의 앱으로 통과한다 |
| 캐릭터 옮기기 | 투명한 부분이나 이동 버튼을 끈다 | 몸통을 눌러 끈다(머리는 쓰다듬기). 위치는 다음 실행에도 유지된다 |
| 누르고 말하기 | Space(페이지에 포커스가 있을 때) | 설정에서 ⌥Space처럼 Ctrl·Option·Cmd가 들어간 단축키로 바꾸면 어떤 앱을 쓰는 중에도 동작한다. 단독 Space는 캐릭터 창에 포커스가 있을 때만 동작한다 |
| 앱·웹사이트 열기 | 가상 앱, 새 브라우저 탭 | 설치된 실제 앱 실행, 기본 브라우저로 웹사이트 열기 |
| 만들기·파일 작업 | 가상 Code 앱에서 작은 앱 제작 | 설정 > 일반 > 에이전트 프로젝트 폴더 안에서 실제 코딩, 파일 작업, 명령 실행 |
| 계정 연결 | 브라우저 안에서 OAuth | 시스템 브라우저로 로그인하고 결과를 키체인에 저장 |
| 메뉴 막대 | 가상 메뉴 막대의 트레이 메뉴 | 실제 메뉴 막대의 YuiYumi 메뉴: YuiYumi 숨기기/보이기, 에이전트…, 설정…, 대시보드…, YuiYumi 종료(⌘Q) |

### 10.5 컴퓨터 작업 맡기기 (데스크톱 앱)

1. 설정 > 일반 > 에이전트 프로젝트 폴더에서 "선택…"을 눌러 작업할 폴더를 고른다. 홈 폴더 전체가 아니라 프로젝트 폴더를 고른다. 폴더를 고르지 않으면 컴퓨터 작업을 하지 않는다.
2. "이 폴더에 할 일 관리 웹앱 만들어 줘"처럼 부탁한다.
3. 진행 내용은 메뉴 막대 > 에이전트… 창에 표시되고, 시작과 끝은 캐릭터가 말로 알려 준다.
4. 파일 쓰기, 명령 실행 등 확인이 필요한 단계에서는 에이전트 창에 허용·거부 버튼이 뜬다. 120초 안에 답하지 않으면 거부된다. 어떤 단계에서 물어볼지는 6.3절의 권한 단계를 따르며, 수동에서는 파일 쓰기·웹 가져오기·명령 실행을, 자동에서는 명령 실행과 프로젝트 폴더 밖 작업을 확인한다.

## 11. 문제 해결

| 증상 | 해결 |
|---|---|
| 캐릭터 소리가 안 들린다 | 페이지를 한 번 클릭한다(브라우저 자동 재생 제한). 컨트롤 필의 스피커 버튼이 켜져 있는지, 기기 음량과 브라우저 탭 음소거를 확인한다 |
| 말을 해도 반응이 없다 | 주소창 왼쪽의 사이트 정보 아이콘에서 마이크 권한을 "허용"으로 바꾸고 페이지를 새로 고친다. 다른 앱이 마이크를 쓰고 있지 않은지 확인한다. 급하면 채팅(키보드 버튼)을 쓴다 |
| Space를 눌러도 녹음되지 않는다 | 입력칸에 커서가 있으면 Space는 글자 입력으로 쓰인다. 빈 곳을 한 번 클릭한 뒤 누르거나 마이크 버튼을 누른다 |
| 다른 언어로 알아듣는다 | 설정 > 음성 > 음성 언어를 확인한다 |
| Google 연결 시 "액세스 차단됨" 또는 403 access_denied | 그 Google 계정이 테스트 사용자로 등록되지 않은 것이다. YuiYumi 팀에 주소 등록을 요청한 뒤 다시 연결한다. Workspace 계정이면 개인 Gmail로 시도한다 |
| Google 연결이 풀렸다 | 테스트 모드 로그인은 약 7일 뒤 만료된다. 설정 > 연결에서 다시 연결한다 |
| 처음 로딩이 오래 걸린다 | 첫 방문에는 캐릭터 모델(약 12MB)을 내려받는다. 다음 방문부터는 빨라진다. 로딩 화면은 일정 시간이 지나면 저절로 닫히며, 캐릭터가 계속 보이지 않으면 페이지를 새로 고친다 |
| 캐릭터가 먼저 말을 걸지 않는다 | 조용히·관상용 모드인지 확인하고, 컨트롤 필의 화면 보기 버튼을 켠다. 활성 모드여도 화면에 말할 만한 변화가 없으면 조용히 있는다. 대시보드의 "마지막 관찰 판단"에서 이유를 볼 수 있다 |
| 캐릭터가 정해진 짧은 대사만 한다 | 네트워크 문제나 데모의 하루 사용량 한도에 걸린 경우다. 잠시 뒤 다시 시도한다 |
| 확인 카드가 계속 뜬다 | 설정 > 권한에서 자동으로 바꾸면 발송·게시만 확인한다 |
| 캐릭터가 사라졌다 | 메뉴 막대 트레이에서 "캐릭터 보이기"를 누르거나 Dock의 YuiYumi 아이콘을 누른다 |
| 처음 상태로 되돌리고 싶다 | 브라우저의 사이트 설정에서 이 사이트의 데이터(쿠키 및 사이트 데이터)를 삭제하고 새로 고친다. 이름, 언어, 설정, 캐릭터 카드가 초기화되고 계정 연결도 해제된다 |
| 데스크톱 앱이 화면을 보지 못한다 | 화면 기록 권한을 허용한 뒤 앱을 완전히 종료(⌘Q)하고 다시 실행한다. 앱을 새 버전으로 바꾼 뒤에는 권한을 다시 허용해야 할 수 있다 |
| 데스크톱 앱에서 단축키가 다른 앱에서 동작하지 않는다 | 단독 키는 전역 단축키로 등록되지 않는다. 설정 > 음성에서 ⌥Space처럼 조합키로 바꾼다 |

## 12. 개인정보와 안전

- **화면**: 화면 캡처는 활성 모드에서만 하며, 약 3초마다 한 장을 판단을 위해 서버로 보낸다. 조용히·관상용 모드에서는 캡처하지 않는다. 단, 이 모드에서 말을 걸면 활성 모드로 바뀌므로 그때부터 다시 캡처한다. 웹 데모는 브라우저 안의 가상 데스크톱만 캡처하고, 데스크톱 앱은 메인 디스플레이를 캡처하되 YuiYumi 자신의 창은 제외한다. 캡처한 이미지는 요청을 처리한 뒤 버리며 서버에 저장하지 않는다.
- **음성**: 누르고 말하기나 VAD로 녹음한 음성은 글자로 바꾸기 위해 서버로 보낸다. 캐릭터의 대사도 음성 합성을 위해 서버로 보낸다.
- **계정**: 웹 데모의 로그인 정보는 암호화한 뒤 브라우저의 httpOnly 쿠키에 담기므로 페이지의 스크립트가 읽을 수 없고, 서버에도 저장하지 않는다. 데스크톱 앱은 macOS 키체인에 저장한다. "연결 해제"를 누르면 삭제된다.
- **발송 제한**: 메일 발송과 메시지 게시는 세션당 10회, 계정당 하루 30회로 제한된다.
- **권한 무시의 의미**: 권한 무시 단계에서는 캐릭터가 확인 카드 없이 메일을 보내고 Slack·Discord에 게시하며, 데스크톱 앱에서는 파일 쓰기와 명령 실행도 묻지 않고 한다. 실제 계정을 연결한 상태에서는 수동 또는 자동 단계를 권장한다.
- **설정 저장 위치**: 이름, 언어, 모드, 권한 단계, 캐릭터 카드는 사용하는 브라우저(또는 데스크톱 앱)에만 저장된다.
