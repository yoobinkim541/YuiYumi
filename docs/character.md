# 캐릭터: 토끼 (TT2.0 / 兔兔2.0)

## 결정

- 서비스의 캐릭터는 **토끼 귀 소녀**이며, 모델 레포의 `TT2.0`(【雪熊企划】兔兔2.0)이다. 랜딩 아트(흰 머리, 빨간 포인트, 검은 물방울 리본, ">" 머리핀)와 같은 캐릭터다.
- `Yui`(자체 모델)는 쓰지 않는다. 서비스 이름 YuiYumi는 그대로 둔다.

## 확인이 필요한 라이선스 (배포 전 필수)

TT2.0은 직접 만든 모델이 아니라 **판매되는 모델**로 보인다.

- 모델 아이콘의 워터마크에 판매처가 **雪熊企划, Bilibili, BOOTH**이고 그 밖의 경로는 해적판이라는 취지의 문구가 있다(워터마크가 일부 겹쳐 있어 정확한 문장은 원본으로 확인).
- 레포의 `TT2.0/yuiyumi.toml` 주석에도 "이 레포에 있는 것이 재배포 허가는 아니다(not a redistribution grant)"라고 적혀 있다.
- Vercel로 웹에 올리면 방문자의 브라우저로 모델 파일(`.moc3`, 텍스처)이 전송된다. 이는 **재배포**에 해당할 수 있다.

해야 할 일:

1. 구매했는지, 구매 약관(BOOTH 등)에서 **상업·공개 이용, 웹 임베드, 파일 재배포, 2차 창작(랜딩 아트 등)**이 허용되는지 확인한다.
2. 불명확하면 판매자(雪熊企划)에게 서면으로 허가를 받는다.
3. 허가를 확인하기 전에는 **공개 배포물에 TT2.0 파일을 넣지 않는다.** 대안은 자체 모델 Yui로 시연하거나, 약관이 허용하는 범위의 녹화 영상으로 보여 주는 것이다(영상 사용 가능 여부도 약관으로 확인).
4. 랜딩 에셋 4장의 제작 방식과 사용 권리도 확인한다.

## 표정 (TT2.0)

레포의 `TT2.0/yuiyumi.toml` 기준.

| 표정 | 설명 |
|---|---|
| 脸红 | 볼터치. 따뜻하고 기쁜 느낌. 입은 립싱크 가능 |
| 害羞嘴 | 당황해 열린 물결 입 |
| 傲娇嘴 | 작게 오므린 "3" 입. 집중하는 듯, 약간 의기양양 |
| 委屈嘴 | 작게 처진 입. 서운함, 미안함 |
| 无语嘴 | 팽팽한 물결 입. 불안, 난처 |
| 震惊嘴 | 작은 동그란 입. 가벼운 "어?" |
| 眼泪 | 눈물 맺힌 눈 |
| 无语 | 반쯤 감은 눈. 졸린 느낌 |
| 震惊 | 하얀 동그란 눈. 너무 강해서 일상 상태에는 부적합 |
| 黑脸 | 어두운 그림자. 귀엽지 않아 사용하지 않음 |

토글: 외투(外套), 귀(耳朵), 손에 든 소품(手机 휴대폰, 手柄 컨트롤러 분홍·빨강·파랑, 麦克风 마이크). 입 모양 5종은 립싱크 중에 입을 숨기므로 말하는 동안에는 비켜난다.

**TT2.0에는 고양이 눈, 하트 눈 같은 눈 표정이 없다.** (그것들은 Yui 모델의 표정이다.)

## 모델의 감정 라벨과 기획 매핑 제안

모델 프로필(`[emotions]`)이 이미 정한 라벨을 기획의 감정 태그로 쓰는 것을 제안한다. 6종 대신 모델의 라벨 9종이다. 개발 쪽 확인이 필요하다.

| 라벨 | 구성 | 기획에서의 쓰임 |
|---|---|---|
| neutral | 기본 얼굴(이미 미소) | 기본, 관찰 중 |
| happy | 脸红 | 인사, 응원, 완료 |
| shy | 脸红 + 害羞嘴 | 칭찬 |
| playful | 脸红 + 傲娇嘴 | 심심함, 놀아 줘 |
| thinking | 傲娇嘴 | 업무·리서치 중, 집중(기존 `focused` 대체) |
| surprised | 震惊嘴 | 놀람, 반복 호출 |
| sorry | 眼泪 + 委屈嘴 | 사과, 공감 |
| troubled | 无语嘴 | 난처함, 경계에서 선 긋기 |
| sleepy | 无语 | 조용히 모드, 졸림 |

`persona-reactions.md`의 감정 태그가 확정되면 위 라벨로 바꾼다. 아직은 기존 6종(`focused`는 `thinking`으로 대체)으로 둔다.

## 작업·리서치 중 애니메이션

TT2.0에는 고양이 눈 표정이 없어서 아래로 대체한다.

- `thinking`(傲娇嘴)을 기본으로 한다. 모델 프로필도 "집중하는 것처럼 보인다"고 정했다.
- 손에 든 **휴대폰(手机) 소품**을 들어 "찾아보는 중"을 연출할 수 있다. 다만 프로필 주석에 따르면 소품은 도구 호출마다 켜지고 꺼지면 양팔이 계속 흔들려 상태에 묶지 않았다. 리서치처럼 길게 이어지는 작업에만 쓰는 것이 낫다.
- 마우스를 따라보는 시선과 고개 모션으로 "생각하는" 느낌을 더한다.
- 완료되면 `happy`로 바뀐다.
