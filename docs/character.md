# 캐릭터: 유이(Yui)와 유미(Yumi)

## 결정

서비스에는 **두 캐릭터**가 나온다. 서비스 이름 YuiYumi는 두 이름을 합친 것이다.

| | 유이 (Yui) | 유미 (Yumi) |
|---|---|---|
| 모델 | 자체 모델 (`YuiYumi-models/Yui`) | 구매한 모델 TT2.0, 【雪熊企划】兔兔2.0 (`YuiYumi-models/TT2.0`) |
| 외형 | 연한 분홍빛 머리, 청록색 눈, 여우 귀와 꼬리 | **토끼 귀 소녀**: 흰 머리, 빨간 포인트, 검은 물방울 리본, ">" 머리핀 (랜딩 아트와 같은 캐릭터) |
| 특징 표정 | 고양이 눈, 하트 눈, 눈 반짝, 꼬리 흔들기 | 볼터치, 오므린 입, 눈물 |
| 랜딩 이미지 | 유빈님이 제작해서 제공 예정 | 있음 |

- **데모는 한 번에 한 캐릭터만 띄우고, 전환 버튼으로 바꾼다.** 두 캐릭터를 화면에 동시에 띄우는 것은 로드맵이다(렌더링·메모리·연출 조율이 두 배라 오늘 범위 밖).
- 기본 캐릭터는 랜딩 아트가 있는 **유미**로 하고, 유이는 전환으로 선택한다. 시간이 모자라면 유이 전환을 먼저 자른다(`spec.md`의 컷 순서).
- 두 캐릭터는 **업무 능력은 같고 말투와 표정만 다르다.** 말투 제안은 `persona-reactions.md`에 있다.
- 캐릭터마다 ElevenLabs 보이스를 하나씩 고른다.
- 유이 소개 이미지가 오면 랜딩에 "Yui & Yumi" 섹션을 추가한다(`landing` 브랜치).
- 유이의 모션은 대부분 게임에서 추출한 파일이다. 공개 배포에는 직접 만든 것과 MIT인 소수(`motions/authored`, `eastasia` 일부)만 쓰고, 쓰기 전에 `SOURCES.jsonl`로 출처를 확인한다. 유이의 대기 모션(`taptc-ri-idle-35a`)도 출처 확인 대상이다.

## 확인이 필요한 라이선스 (배포 전 필수)

TT2.0은 직접 만든 모델이 아니라 **판매되는 모델**로 보인다.

- 모델 아이콘의 워터마크에 판매처가 **雪熊企划, Bilibili, BOOTH**이고 그 밖의 경로는 해적판이라는 취지의 문구가 있다(워터마크가 일부 겹쳐 있어 정확한 문장은 원본으로 확인).
- 레포의 `TT2.0/yuiyumi.toml` 주석에도 "이 레포에 있는 것이 재배포 허가는 아니다(not a redistribution grant)"라고 적혀 있다.
- Vercel로 웹에 올리면 방문자의 브라우저로 모델 파일(`.moc3`, 텍스처)이 전송된다. 이는 **재배포**에 해당할 수 있다.

**확인 결과 (김유빈, 2026-10-24)**: TT2.0은 **구매한 모델**이고, 별도의 이용 약관은 없으며, **상업적 사용은 하지 않는 조건**으로 사용하므로 약관을 충족하는 것으로 확인했다.

남은 주의점(기록용):

- 서면 약관이 없으므로 이 판단은 구매 조건에 대한 이해에 근거한다. 상업적 사용(수익화, 유료 서비스 등)으로 넘어가기 전에는 판매자(雪熊企划)에게 다시 확인한다.
- 현재 랜딩페이지는 정지 이미지만 사용하며 모델 파일(`.moc3`, 텍스처)을 배포하지 않는다. 앱 데모에서 모델 파일이 방문자의 브라우저로 전송되는 방식이 되는 시점에, 위 조건이 그대로 유지되는지 한 번 더 점검한다.
- 랜딩 에셋 4장의 제작 방식과 사용 권리는 별도로 알고 있어야 한다.

## 모델의 감정 라벨과 기획 매핑 제안

**두 모델의 프로필(`[emotions]`)이 같은 9종 라벨**(neutral, happy, shy, sorry, troubled, surprised, thinking, playful, sleepy)을 쓴다. 이 라벨을 기획의 감정 태그로 쓰는 것을 제안한다. 6종 대신 9종이며, 어느 캐릭터든 같은 태그로 호출하면 각 모델이 자기 표정으로 보여 준다. 개발 쪽 확인이 필요하다.

아래 표의 "구성"은 유미(TT2.0) 기준이다. 유이는 같은 라벨을 다른 표정 조합으로 낸다: happy = 눈반짝·미소·꼬리흔들기, shy = 뀨잉, sorry = 눈물·슬픔, troubled = 눈빙글·볼빵빵, surprised = 눈땡글·놀람, playful = 메롱·하트이펙트·꼬리흔들기, thinking과 sleepy = 기본 얼굴.

| 라벨 | 구성 | 기획에서의 쓰임 |
|---|---|---|
| neutral | 기본 얼굴(이미 미소) | 기본, 관찰 중 |
| happy | 脸红 | 인사, 응원, 완료 |
| shy | 脸红 + 害羞嘴 | 칭찬 |
| playful | 脸红 + 傲娇嘴 | 심심함, 놀아 줘 |
| thinking | 傲娇嘴 | 업무·리서치 중, 집중(기존 `focused` 대체) |
| surprised | 震惊嘴 | 놀람, 반복 호출 |
| sorry | 眼泪 + 委屈嘴 | 사과, 공감 |
| troubled | 无语嘴 | 난처함, 경계에서 선 긋기 |
| sleepy | 无语 | 조용히 모드, 졸림 |

`persona-reactions.md`의 감정 태그가 확정되면 위 라벨로 바꾼다. 아직은 기존 6종(`focused`는 `thinking`으로 대체)으로 둔다.

## 작업·리서치 중 애니메이션

**유이**는 `고양이눈` 표정(하얀 슬릿 눈)이 있어서 리서치 중 "흥미" 연출에 쓸 수 있다. **유미(TT2.0)**에는 고양이 눈 표정이 없어서 아래로 대체한다.

- `thinking`(傲娇嘴)을 기본으로 한다. 모델 프로필도 "집중하는 것처럼 보인다"고 정했다.
- 손에 든 **휴대폰(手机) 소품**을 들어 "찾아보는 중"을 연출할 수 있다. 다만 프로필 주석에 따르면 소품은 도구 호출마다 켜지고 꺼지면 양팔이 계속 흔들려 상태에 묶지 않았다. 리서치처럼 길게 이어지는 작업에만 쓰는 것이 낫다.
- 마우스를 따라보는 시선과 고개 모션으로 "생각하는" 느낌을 더한다.
- 완료되면 `happy`로 바뀐다.
