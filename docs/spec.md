## 한 줄 정의

일하는 동안 옆에서 눈치껏 한마디 하고, 시킨 일은 초안까지 해두는 캐릭터.

컴패니언은 정은 있지만 일을 못 하고, 에이전트는 일은 하지만 정이 없다. 캐릭터가 일의 맥락을 읽는 능력(눈치)으로 정을 만든다. 연애·성인 요소 없음, 일 잘하는 같은 팀 동료.

## 제품 형태

- **Vercel(Next.js)**: `/api/*`(Claude, ElevenLabs, 눈치 게이트), `/`(랜딩 + 90초 웹 데모, 심사 링크), `/download`
- **Tauri 앱**: 투명·항상 위 창에 캐릭터를 띄우고 Vercel `/api`를 호출
- **심사 링크만으로 데모가 완결**되어야 한다. 웹 데모는 가짜 데스크톱 위에 같은 캐릭터를 띄우고, 화면 맥락은 **스크립트 장면**이다(제출물에 명시).
- Tauri는 제품 증명(영상·설치 파일)이며 웹이 끝난 뒤에 진행한다.

## 눈치 엔진

입력: 활성 앱 종류, 같은 화면 체류 시간, 화면 텍스트 요약과 언어, 마지막 끼어들기 후 경과 시간, 오늘 끼어든 횟수.

1. **규칙 게이트(결정적, LLM 호출 전)**: 하루 3회 초과, 마지막 끼어들기 후 10분 이내, 같은 화면 체류 20초 미만, 사용자가 "조용히" 설정, 사용자 발화·타이핑 중이면 침묵
2. **판단(Haiku, 짧은 JSON)**: `{speak, reason, line, offer}`
3. **실행(Sonnet tool use)**: 사용자가 확인 카드를 수락한 경우에만

## 90초 데모

| 시간 | 장면 |
|---|---|
| 0–10초 | 문제 제시, 캐릭터 등장 |
| 10–30초 | 영어 메일을 읽는 사용자, 캐릭터는 곁눈질, 말은 안 함 |
| 30–50초 | 20초 후 "답장 초안 써 줄까?" → 확인 카드 |
| 50–70초 | 초안 저장, "발송은 네가 직접 해" |
| 70–85초 | "오후 3시 미팅이랑 겹쳐" 충돌 경고 |
| 85–90초 | 호감도 상승, 해금될 의상 예고, 로드맵 한 줄 |

타이핑 중 침묵하는 장면을 하나 반드시 넣는다(눈치를 가장 잘 보여준다).

## 감정과 캐릭터

감정 6종: neutral, happy, thinking, surprised, sorry, focused. 모델의 표정·모션 이름은 매핑 파일에서 연결한다. Live2D 샘플 모델의 공개 배포 라이선스는 확인 필요. 11:45까지 렌더링이 안 되면 2D 스프라이트 표정 교체로 폴백한다.

## 합격 기준

- AC-1: 장면 A에서 20초 후 캐릭터가 말을 건다
- AC-2: 타이핑 중인 장면에서는 말을 걸지 않는다
- AC-3: 하루 3회를 넘기면 말하지 않는다
- AC-4: 확인 카드를 수락해야만 초안이 저장된다
- AC-5: 거절하면 아무것도 저장되지 않는다
- AC-6: 발송·삭제 도구는 코드에 존재하지 않는다
- AC-7: 웹 링크가 로그인 없이 열리고 90초 데모가 끝까지 돈다
- AC-8: API 실패 시 준비된 대사로 폴백하고 화면이 멈추지 않는다
