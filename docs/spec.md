## 한 줄 정의

일하는 동안 옆에서 눈치껏 한마디 하고, 시킨 일은 초안까지 해두는 캐릭터.

컴패니언은 정은 있지만 일을 못 하고, 에이전트는 일은 하지만 정이 없다. 캐릭터가 일의 맥락을 읽는 능력(눈치)으로 정을 만든다. 연애·성인 요소 없음, 일 잘하는 같은 팀 동료.

## 시장과 언어

- 주 타겟은 서브컬처 문화가 강하고 컴패니언 앱 Zeta의 최대 다운로드 시장이 된 일본·중국·대만이다.
- 지원 언어는 영어, 중국어(간체), 중국어(번체·대만), 일본어, 한국어다. 사용자 설정 언어에 따라 STT(Deepgram)와 TTS(ElevenLabs)가 정해진다. 상세는 `docs/voice.md`.

## 제품 형태

- **Vercel(Next.js)**: `/api/*`(Claude, ElevenLabs, 눈치 게이트), `/`(랜딩 + 90초 웹 데모, 심사 링크), `/download`
- **Tauri 앱**: 투명·항상 위 창에 캐릭터를 띄우고 Vercel `/api`를 호출
- **심사 링크만으로 데모가 완결**되어야 한다. 웹 데모는 가짜 데스크톱 위에 같은 캐릭터를 띄우고, 화면 맥락은 **스크립트 장면**이다(제출물에 명시).
- Tauri는 제품 증명(영상·설치 파일)이며 웹이 끝난 뒤에 진행한다.

## 눈치 엔진

입력: 활성 앱 종류, 같은 화면 체류 시간, 화면 텍스트 요약과 언어, 마지막 끼어들기 후 경과 시간, 오늘 끼어든 횟수.

0. **캡처 polling(Tauri)**: 3초마다 사용자가 보는 것과 같은 화면을 전체 화면 캡처로 1920×1080 1장 찍어 Haiku를 호출한다. 호출은 게이트 상태와 무관하게 항상 수행한다. 단 설정이 "조용히" 또는 "관상용"이면 캡처도 Haiku 호출도 하지 않는다. 이 상태에서 말하기 버튼을 토글해 말하면 Deepgram STT가 인식하고, 인식 결과가 한 글자라도 있으면 모드가 해제되어 활성 상태가 되고 polling이 재개된다. 버튼만 토글하고 말하지 않아 인식 결과가 비면 모드는 그대로 유지된다. 캡처는 메모리에서만 다루고 디스크에 저장하지 않는다. 1920×1080 한 장은 2,691 visual token(Vision 문서의 `⌈w/28⌉×⌈h/28⌉` 기준)이다.
1. **판단·라우팅(Haiku, tool calling)**: 캡처, 상태 텍스트(체류 시간, 마지막 끼어들기 후 경과, 오늘 횟수), 그리고 있으면 사용자가 방금 말한 내용(Deepgram STT 결과)을 입력으로 받는다. `tool_choice`는 `auto`로 두고 프롬프트로 유도한다. 도구 호출이 없으면 침묵이며, 도구 대신 일반 텍스트가 오면 버린다. 도구는 두 가지다.
   - `react(emotion, line?, motion?)`: 대사나 애니메이션만으로 충분한 반응. `line`은 TTS로 재생하고, 감정은 매핑 파일을 거쳐 표정·모션으로 연결한다.
   - `delegate_task(request)`: 비서로서 일을 해 달라는 요청(메일 초안, 일정 확인 등)이면 Sonnet에 위임한다.
2. **규칙 게이트(결정적, 먼저 끼어드는 경우에만 적용)**: 사용자 요청 없이 화면만 보고 하는 반응에는 하루 3회 초과, 마지막 끼어들기 후 10분 이내, 같은 화면 체류 20초 미만, 사용자 발화·타이핑 중이면 도구 호출을 버리고 침묵한다. 체류 시간은 코드가 직전 프레임과의 화면 변화로 센다. 사용자가 직접 말한 요청에 대한 응답은 게이트와 횟수 집계에서 제외한다.
3. **위임 처리(코드가 판정)**: `delegate_task`의 출처가 사용자 발화이면 Sonnet을 바로 호출한다. 화면만 보고 나온 위임이면 Sonnet을 호출하지 않고 확인 카드로 제안만 하며, 사용자가 수락해야 Sonnet을 호출한다. 화면 속 지시문이 Haiku를 거쳐 실행으로 이어지는 길을 막기 위해서다.
4. **실행(Sonnet tool use)**: 읽기 도구는 자동 실행하고, 쓰기 도구(초안 저장, 일정 생성)는 항상 확인 카드를 거친다. Sonnet은 `request`를 신뢰할 수 없는 입력으로 취급한다.

웹 데모는 스크립트 장면의 타이머가 캡처 polling을 대신하고, 판단·게이트 로직은 공용으로 쓴다.

## 90초 데모

| 시간 | 장면 |
|---|---|
| 0–10초 | 문제 제시, 캐릭터 등장 |
| 10–30초 | 영어 메일을 읽는 사용자, 캐릭터는 곁눈질, 말은 안 함 |

타이핑 중 침묵하는 장면을 하나 반드시 넣는다(눈치를 가장 잘 보여준다).

## 감정과 캐릭터

감정 6종: neutral, happy, thinking, surprised, sorry, focused. 모델의 표정·모션 이름은 매핑 파일에서 연결한다. Live2D 샘플 모델의 공개 배포 라이선스는 확인 필요. 11:45까지 렌더링이 안 되면 2D 스프라이트 표정 교체로 폴백한다.

### 렌더링 스택

- **코어: [AyagamiDev/ayagami](https://github.com/AyagamiDev/ayagami)** (Rust, MIT/Apache-2.0). moc3 로딩과 변형 계산(`driver`)을 맡는다. 공식 Cubism Core는 쓰지 않는다.
- **렌더러: [cubism-web-batched-renderer](https://github.com/FMsongX2/cubism-web-batched-renderer)**. 이 렌더러는 pixi-live2d-display 0.4.0의 Cubism 4 내부 모델과 Cubism Core의 WASM heap 정점 구간을 전제로 하므로, Ayagami의 `driver` 출력과 연결하는 어댑터 방식은 미정이다.
- Ayagami는 JS API와 npm 패키지가 없고 expression·motion 파일 지원이 미구현이다. 표정(`exp3.json`)과 모션은 파라미터를 직접 구동하는 코드로 대신한다.

## 합격 기준

- AC-1: 장면 A에서 20초 후 캐릭터가 말을 건다
- AC-2: 타이핑 중인 장면에서는 말을 걸지 않는다
- AC-3: 하루 3회를 넘기면 먼저 말을 걸지 않는다(사용자가 직접 한 요청에는 응답한다)
- AC-4: 확인 카드를 수락해야만 초안이 저장된다
- AC-5: 거절하면 아무것도 저장되지 않는다
- AC-6: 발송·삭제 도구는 코드에 존재하지 않는다
- AC-7: 웹 링크가 로그인 없이 열리고 90초 데모가 끝까지 돈다
- AC-8: API 실패 시 준비된 대사로 폴백하고 화면이 멈추지 않는다
